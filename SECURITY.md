# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If the affected repository provides GitHub private vulnerability reporting,
use that mechanism.

Otherwise, contact the repository owner privately before disclosing the
vulnerability publicly.

When reporting a vulnerability, please include when possible:

- the affected repository and version;
- a description of the vulnerability;
- steps to reproduce;
- the potential impact;
- any suggested mitigation.

## Disclosure

Please allow reasonable time for investigation and remediation before
publishing details of a vulnerability.
